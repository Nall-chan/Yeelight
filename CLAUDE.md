# Diese Library: Yeelight  

- Diese Library dient zur Anbindung von dem Yeelight Geräten an die Software Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um Yeelight Geräte in Netzwerk aufzufinden, abzufragen und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist.
